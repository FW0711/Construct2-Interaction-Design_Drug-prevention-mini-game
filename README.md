## 🌐 專案介紹 / Project Details

<details>
<summary><b>📌 中文說明 (Click to expand Chinese version)</b></summary>

### 專案簡介
本專案為反毒宣導主題之 HTML5 互動微遊戲，透過遊戲化設計（Gamification）傳遞反毒知識與觀念。

### 核心功能與特色
* **互動體驗**：玩家可透過簡單直覺的操作進行遊戲關卡挑戰。
* **跨平台支援**：採用 HTML5 開發，可直接於主流瀏覽器上執行。
* **宣導效益**：結合寓教於樂的方式提升學習動機。

### 開發工具
* **遊戲引擎**：Construct 2
* **部署平台**：GitHub Pages

</details>

### Overview
This project is an HTML5 interactive mini-game designed for anti-drug education, using gamification to deliver educational content effectively.

### Features
* **Interactive Gameplay**: Intuitive controls and accessible level design.
* **Cross-Platform**: Developed in HTML5, runs directly on standard web browsers.
* **Educational Purpose**: Combines fun and learning to increase awareness.

### Built With
* **Game Engine**: Construct 2
* **Deployment**: GitHub Pages
